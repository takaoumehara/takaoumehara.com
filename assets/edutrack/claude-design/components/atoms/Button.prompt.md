Rectangular Oswald-uppercase action button; use `solid` for the primary action on a screen, `flag` only for assignment/warning actions.

```jsx
<Button onClick={save}>START PLANNING</Button>
<Button variant="outline" size="sm">GO TO PLAN</Button>
```

Variants: solid (accent), flag (orange), outline, ghost. Sizes sm/md/lg. Never rounded, never more than one solid button per view.
