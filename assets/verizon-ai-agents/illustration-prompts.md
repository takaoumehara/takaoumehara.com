## Style Prefix (prepend to all prompts)

```
[GIG] ULTRA-CLEAR CONCEPTUAL DIAGRAMS (Flat/Isometric Hybrid)
Overall Aesthetics: Create ultra-clean, highly functional, and sophisticated conceptual diagrams. The aesthetic is "whitened", high-end, and light-filled, prioritizing absolute visual clarity and maximum "airiness" (spatial freedom). The style must remain topic-agnostic, capable of illustrating any abstract concept with pristine precision.

Representation: This is a hybrid instruction. Use simplified isometric 3D perspective when showing spatial relationships, interaction between distinct components, or an overall system overview. Use clean flat 2D vector representation for process flows, hierarchical structures, or logical schematics. Both styles must coexist seamlessly.

Color Palette (Mandatory & Strict): Orange (#F59400), Blue (#6C82FE), Pink (#FC6978), Element White (#FFFFFF), Matte Black (#111111), Light Gray (#EEEEEE) background.
Line Work: Perfectly clean, uniform-weight matte black outlines (#111111). No soft or textured outlines.
Shading: Soft-cell shading for isometric only. Zero shading on flat elements. No gradients.
RULE: Every element must serve the concept. No decorative objects. Airiness over density.
```
