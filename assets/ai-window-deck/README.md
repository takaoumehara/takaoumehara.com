# assets/ai-window-deck — 受け入れ待ちの素材

`projects/ai-window-deck.html` の Evidence スライドは、下のファイル名を前提に組んである。
このディレクトリにコミットしたうえで、HTML 内の `.g-cell.is-pending` を
`<img>` に差し替えれば表示に切り替わる（差し替え方は各スライドのコメントに記載）。

| ファイル名 | 中身 | 置き場所 |
|---|---|---|
| `sketch-1.jpg` 〜 `sketch-3.jpg` | 手書きワイヤーフレーム3枚 | Evidence · Sketches（dark） |
| `ui-monitors.png` | 実在モニターのカード表示 | Evidence · Interface（cream） |
| `ui-canvas-dnd.png` | キャンバスへのドラッグ＆ドロップ | 同上 |
| `ui-resize.png` | 枠のリサイズハンドル | 同上 |
| `ui-layout-search.png` | レイアウト検索ドロップダウン | 同上 |
| `hero.jpg`（任意） | Hero 背景。横長・明るめでよい（暗いスクリムを重ねる） | Hero |

`hero.jpg` を入れる場合は `.wds-hero` の `background` を、同じルールの
コメントに書いてある3層版に置き換える。

スクリーンショットは**実画面のみ**。モックアップ画像で代用しない
（`docs/portfolio-content-intake-prompt.md` §8）。
