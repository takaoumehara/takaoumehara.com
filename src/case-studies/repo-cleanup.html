Survey, protect, then clean 調べて、守って、片づける

repo-cleanup surveys the tree first, protects secret patterns, untracks mistracked generated files, completes .gitignore, then sorts remaining changes into commit, stash, or discard — only after showing a plan. It refuses git add -A and never discards work irreversibly.
