Built for a 2–3 second window 2〜3 秒という時間から逆算する

The donut-wheel hub is the whole interaction: large touch targets a teacher can hit without looking down, an at-a-glance roster, and a radial layout built specifically for the gap between one student interaction and the next. ドーナツ型のハブが、操作のすべてを担う。見なくても押せる大きなタップ範囲、一目で分かる名簿、そして生徒対応の合間という短い時間のために作った放射状のレイアウト。

Designed alongside teachers, not behind glass ガラス越しではなく、教師と共に設計する

Workshops put teachers and designers at the same wall, voting on priorities and mapping requirements together before a single screen was drawn — the constraint that shaped the whole interface came out of that room, not a spec sheet. ワークショップでは、教師とデザイナーが同じ壁に向かい合い、優先順位に投票し、要件を一緒に書き出した。画面を 1 枚も描く前に、インターフェース全体を決めた制約は、この場から出てきたもので、仕様書からではない。

From charrette sketches to a flow ワークショップの手描きから、画面の流れへ

Each group's sketches and "how might we" questions were turned into application flows that map the teacher's interaction model. 各グループの手描きと「どうすれば〜できるか」という問いを、アプリの流れに落とし込んだ。教師がどう操作するかを、一本の流れとして描いている。

Five rounds, tested where it would actually be used 実際に使う場所で、5 回試した

Five rounds of classroom testing refined the interaction states — sorting, student cards, conference input and skill tracking. 教室での 5 回のテストで、操作の状態を一つずつ詰めた。並べ替え、生徒カード、面談の入力、スキルの記録。
