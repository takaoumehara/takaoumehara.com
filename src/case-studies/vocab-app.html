Two panes make the gap visible 2 つのペインで、抜けを見えるようにする

The master library sits on the left, the list being built sits on the right — both searchable and filterable by stream and grade, so an author can see what exists and what's selected at the same time, instead of holding it in their head across spreadsheets. 左にマスターライブラリ、右に作成中のリストを置いた。どちらも Stream と学年で絞り込める。何があって、何を選んだかを同時に見られるので、複数の表計算ソフトを頭の中で突き合わせる必要がなくなる。

Every import is reviewed before it's committed 取り込みは、確定する前に必ず確認する

A bulk CSV import surfaces duplicates and malformed rows inline, as a side-by-side comparison — this word exists already with one definition, the import has another — so the author decides before the data is committed, not after. CSV の一括取り込みでは、重複や不備のある行をその場で表示する。同じ単語がすでに別の定義で存在する場合、両方を並べて見せる。データが確定する前に、担当者がその場で判断できる。

Nothing is removed without a way back 消すときは、必ず戻せる

Every destructive action, like removing a word from a list, gets a confirmation step and an undo path. Adding words gets the same undo. リストから単語を外すような、データを消す操作には、確認の手順と元に戻す手段を付けた。単語を加えたときも、同じように元に戻せる。
