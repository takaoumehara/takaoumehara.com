One window per project プロジェクトごとに一つのウィンドウ

AI Window Deck is a Chrome extension for people who run Claude Code in the cloud and Codex on more than one project at a time. It keeps track of those windows so moving between projects stays quick. Open source under MIT; setup is on the docs site. AI Window Deck は、クラウド版 Claude Code と Codex で複数のプロジェクトを同時に進める人のための Chrome 拡張。それぞれのウィンドウを把握し、プロジェクト間の行き来を速くする。MIT ライセンスで公開しており、導入方法はドキュメントサイトにある。
