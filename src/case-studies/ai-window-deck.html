Draw the deck before you open it 開く前に、画面の上で決めておく

The settings page is a small map of the screen. Each tile is one window with a name and one or more addresses, which open as tabs. Pick a count or a grid, resize the tiles, choose the monitor, and Launch opens every window at once. Saved decks live in Chrome's synced storage, so they follow you to another computer signed in to the same Chrome. There is no server and no account of its own. 設定画面は、画面の縮図になっている。1 枚のタイルが 1 つのウィンドウで、名前と、タブとして開くアドレスを持つ。枚数かグリッドを選び、タイルの大きさを整え、モニターを選んで「Launch」を押すと、全部のウィンドウが一度に開く。保存した構成は Chrome の同期ストレージに入るので、同じ Chrome にログインした別のパソコンにもついてくる。専用のサーバーもアカウントもない。

One key out, the same key back 同じキーで大きくし、同じキーで戻す

⌥X (Alt+X on Windows) enlarges the window you are in to the size you chose — half, three quarters, full height only, full screen or a custom size — around its own centre or in the middle of the screen. Press it again and it lands back in the exact tile it left. An earlier version cycled tile, enlarged, full screen, so every time you only wanted a little more room you had to pass through full screen; full screen moved to its own key, ⌥Q. The way home is kept in session storage, because a Manifest V3 service worker can stop at any moment. ⌥X（Windows では Alt+X）で、いま使っているウィンドウが選んだ大きさに広がる。半分、4 分の 3、縦だけいっぱい、全画面、自由な寸法。広げる起点は、そのウィンドウの中心か画面の中央。もう一度押すと、出てきたタイルにぴったり戻る。以前は「タイル → 拡大 → 全画面」の 3 段で、少し広げたいだけでも毎回全画面を通らされた。全画面は専用の ⌥Q に分けた。戻り先はセッションストレージに残す。Manifest V3 の Service Worker は、いつ止まってもおかしくないからだ。

Four keys under the left hand 左手だけで届く 4 つのキー

The four default keys — ⌥X spotlight, ⌥Z back to the original tile, ⌥A re-tile, ⌥Q full screen — sit under the left hand, so the right one stays on the mouse. Control combinations were dropped because on a Mac ⌃C is an easy slip for ⌘C, and the Alt keys Windows Chrome already uses — Alt+F, Alt+E, Alt+D, Alt+Space — were avoided. Chrome gives an extension only four default keys, so undo, next and previous window and jump to window 1–8 are registered without keys, for people to assign. When windows drift, ⌥A puts them back in the order they already sit, and the last ten arrangements can be undone. 既定の 4 つ（⌥X 拡大、⌥Z 元のタイルへ、⌥A 並べ直し、⌥Q 全画面）は、すべて左手で押せる。右手はマウスに置いたままでいい。Ctrl 系はやめた。Mac では ⌃C が ⌘C の押し間違いとして起きやすいからだ。Windows の Chrome が使っている Alt+F・Alt+E・Alt+D・Alt+Space も避けた。拡張が持てる既定キーは 4 つまでなので、やり直し、次と前のウィンドウ、ウィンドウ 1〜8 への移動は、キーなしで登録してある。散らかったら ⌥A で、いまの並び順のままグリッドに戻る。直前の配置は 10 回までやり直せる。
