One shape language, four grades ひとつの図形の言葉で、4 学年を

The identity is a navy-and-orange geometric vocabulary — dotted grids, circles, arcs, triangles, dashed line-work. Each grade gets its own composition of the same shapes, so Grade 9 through Grade 12 feel distinct and still clearly one family. Montserrat carries the type, chosen partly because it is a free Google font that works in print and on screen: an open curriculum should not depend on a font people have to pay for. ブランドの軸は、ネイビーとオレンジの幾何学の語彙。点のグリッド、円、弧、三角、破線。学年ごとに同じ図形を別の構成で組むので、9 年生から 12 年生まで、それぞれ違って見えて、ひと目で同じ家族だと分かる。書体は Montserrat。無料の Google フォントで、紙にも画面にも向くことが選んだ理由のひとつだ。オープンな教材が、お金を払う書体に頼るわけにはいかない。

A brighter palette for each text 作品ごとに、明るい色を

The literary units needed to feel like the books they are built around, from The Great Gatsby to Things Fall Apart. A brighter, more expressive palette gives each text its own cover while the shape system keeps them inside the program. Stylescapes set the mood for the whole range before any cover was final. 文学のユニットには、それぞれの題材の本らしさが要る。『グレート・ギャツビー』から『崩れゆく絆』まで。より明るく表情のある配色で作品ごとに表紙を変え、図形の仕組みがそれを同じプログラムの中にとどめる。表紙を決める前に、スタイルスケープで全体の空気を先に決めた。

From stylescape to cover to lesson page スタイルスケープから、表紙へ、授業のページへ

Each unit’s pattern is one asset used everywhere: the stylescapes set the range, the pattern becomes the cover, and the same pattern frames the unit’s pages on the website. That is how a sprawling curriculum reads as one product across print and screen. ユニットごとの模様は、ひとつの素材としてどこにでも使う。スタイルスケープで幅を決め、模様が表紙になり、同じ模様がウェブサイトのそのユニットのページを縁どる。こうして、大きなカリキュラムが、紙でも画面でもひとつのプロダクトとして読める。

The structure first 先に、構造を

Before designing screens I mapped the information architecture and wrote teacher user stories — a teacher coming to the program for the first time, one returning to prepare a unit, one about to teach a lesson — then wireframed the deepest pages, sections, lessons and activities, where a teacher actually works. 画面をつくる前に、情報の構造を描き、教師のユーザーストーリーを書いた。初めてプログラムに来た教師、ユニットの準備に戻ってきた教師、これから授業をする教師。そのうえで、教師が実際に作業するいちばん奥のページ、セクション、授業、活動の画面から線画を起こした。

Then the website それから、ウェブサイト

The program website at ela.odelleducation.com follows that structure: grade landing pages, unit overviews, sections, lessons and activities, all on the same visual system as the printed covers. ela.odelleducation.com のサイトは、その構造のままだ。学年のトップ、ユニットの概要、セクション、授業、活動。すべてが印刷の表紙と同じ見た目の仕組みでできている。
