Only the newest word is sharp くっきりしているのは、最後の言葉だけ

A word holds its shape only while it is new. Everything typed before it stays on screen but loosens into points and drifts, so the space keeps a short, fading history of what was written without ever turning into a page of text. 言葉が形を保つのは、打ったばかりのあいだだけ。それより前に打った言葉も画面には残るが、点にほどけて漂っていく。だから空間には、書かれたことの短い履歴が薄れながら残り、それでも文章のページにはならない。

Composed, not generated 生成ではなく、構成

There is no AI inside Typespace. The gathering, the hold and the return are authored in React Three Fiber, GLSL and Web Audio, so the type behaves like architecture you move through rather than an overlay a machine improvised. Agents helped write the code; none of them run in the piece. Typespace の作品の中に AI はない。集まる、とどまる、還るという動きは、React Three Fiber と GLSL と Web Audio で作り込んである。だから文字は、機械が即興で重ねたレイヤーではなく、中を抜けていける建築としてふるまう。コードを書くのにはエージェントの手も借りたが、作品の中では一つも動いていない。
