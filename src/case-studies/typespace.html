Composed, not generated 生成ではなく、構成

There is no generative pipeline in Typespace. Every cluster, orbit and sound cue is authored in Next.js, React Three Fiber, GLSL and Web Audio, so the type behaves like architecture you move through rather than an overlay the machine improvised. Typespace に生成パイプラインはない。星団も軌道も音の合図も、Next.js / React Three Fiber / GLSL / Web Audio で一つずつ作っている。だから文字は、機械が即興で重ねたレイヤーではなく、歩いて抜けられる建築としてふるまう。
