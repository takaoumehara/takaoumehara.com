No host throne ホストの玉座をつくらない

The two phones link peer-to-peer over WebRTC and the server drops out of the game loop entirely. Lives are shared and a tether runs between the ships, so the game is co-op by construction — there is no player-one seat for anyone to lose. 2 台のスマホは WebRTC で直接つながり、ゲーム中はサーバーを通らない。残機は共有で、2 機のあいだには糸が張られている。つまり構造からして協力プレイで、取り合いになる「1P の席」がそもそも存在しない。
