The interface is part of the story UI そのものが物語の一部

In "Declare Yourself!", students argue the Declaration of Independence as members of the Second Continental Congress — so the navigation is built from the historical drawers found in congress buildings. Each of the four main sections "pulls out" like a drawer, which made the interface tactile and period-appropriate instead of a generic app shell around historical content. 「Declare Yourself!」では、生徒が独立宣言をめぐる大陸会議の議員として議論する。そのため、ナビゲーションは議事堂の引き出しを模した。4 つの主要セクションは、それぞれ引き出しのように「引き出す」動きで開く。歴史教材が、時代がかった操作感を伴う体験になった。

A companion app so no teacher preps alone 教師が一人で準備しなくていいように

Alongside the student experience, I designed a teacher-facing app that walks a teacher through each Quest's five days — scripts, pacing and assessment in one place — so a teacher new to a Quest could open Day 1 and run a well-crafted lesson without separate prep time. 生徒向けの体験とは別に、教師用のアプリも設計した。5 日分の台本・進行・評価が 1 か所にまとまっているので、その Quest を初めて扱う教師でも、Day 1 を開けばそのまま質の高い授業を進められる。
