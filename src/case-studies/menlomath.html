Six identical units become six visible stories 同じに見えた 6 つの単元が、それぞれの物語になる

The home screen listed six units as plain text rows with small, repeating thumbnails — nothing distinguished a ratio unit from a data unit until it was opened. The redesign turned it into a photographic card grid, each unit leading with the real-world hook it was already built on. もとのホーム画面は、6 つの単元をただのテキスト行と小さな使い回しのサムネイルで並べていた。比率の単元もデータの単元も、開くまで見分けがつかない。作り直したホーム画面は写真カードの並びにし、それぞれの単元がもともと持っていた実生活の題材を、開く前から見せるようにした。

The graph didn't change. The scene around it did グラフ自体は変えず、その周りの場面を変えた

An activity screen used to be a bare position-time graph with no thematic context. The rebuilt version keeps the same underlying simulation, graph and data table, but sets them inside a themed scene — a soccer field instead of an abstract line — so the math stays connected to the story a student is already following. 改修前の活動画面は、文脈のない裸のグラフだった。作り直した画面は、同じシミュレーション・グラフ・データテーブルをそのまま使いながら、抽象的な線ではなくサッカーの試合場という題材に沿った場面の中に置いた。生徒が追っている物語と、数学がつながったままになる。

Walkthrough ウォークスルー

Worked out on the wall with the curriculum team カリキュラムのチームと、壁の前で詰めた

The redesign was workshopped with the SunBay Math curriculum team and product stakeholders: user flows and concept sketches on the wall, requirements mapped on sticky notes, and stakeholder personas drawn by hand. 改修の中身は、SunBay Math のカリキュラムのチームや製品の関係者とのワークショップで詰めた。壁に画面の流れとコンセプトのスケッチを貼り、付箋で要件を整理し、関係者の人物像を手で描いた。
