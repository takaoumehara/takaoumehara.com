01 · Problem

The costly amnesia of coding agents

AI agents operate without long-term memories of local build configurations, brittle dependencies, or tricky API quirks, repeatedly stubbing their toes on the exact same error each session.

02 · The CLI

Zero dependencies, maximum portability

Engineered as a lightweight POSIX shell and Node CLI (`ff`) that sits on the global PATH, writing plain human-readable Markdown files that can be committed alongside repositories.

03 · Taxonomy

Root-cause first recording

Forbids superficial symptom patching. Every record forces a four-part diagnosis: category (build, type, test, lint, logic), severity (p0–p3), root cause, and concrete verifiable fix.

04 · Recall Engine

Proactive session-start intelligence

Before a complex refactor or debugging turn begins, failforward automatically searches the local index for matching symptoms and injects past remedies directly into the agent context.

05 · Compatibility

Universal across agent frameworks

Integrates natively into Claude Code hooks, Google Antigravity IDE global rules, OpenAI Codex conventions, and Gemini CLI workflows.
