Your coding agent stops repeating yesterday's mistakes.エージェントが、昨日と同じ失敗を繰り返さなくなる。

failforward is a zero-dependency CLI plus Claude Code skill that records every build, test, and lint failure as plain Markdown — then recalls the relevant ones before similar work begins. Convention files extend it to Codex, Gemini, and Qwen.failforward は、ビルド・テスト・リントの失敗を素の Markdown で記録して、似た作業に入る前にその失敗を呼び戻してくれる、依存ゼロの CLI と Claude Code スキルです。規約ファイルを置けば、Codex・Gemini・Qwen でも同じように使えます。

Every failure recorded. Every lesson recalled.失敗はすべて記録して、必要なときに呼び戻す。

Capturing a mistake is easy; remembering to check for it next time is the hard part. failforward automates the second half: a PostToolUse hook records failures as they happen, and a lightweight token-overlap search surfaces the relevant ones before you repeat the same class of error — scoped per-project or globally, with a built-in eval command to measure how well recall is actually working.失敗を記録するのは簡単です。難しいのは、次に同じ場面が来たとき、それを見に行くのを忘れないことです。failforward は、その後半を自動でやります。PostToolUse のフックが失敗をその場で書き留め、単語の重なりを見る軽い検索が、同じ種類の間違いを繰り返す前にその記録を出してくれます。プロジェクト単位でも全体でも使えて、呼び戻しがどれだけ効いているかを測る eval コマンドも入っています。
