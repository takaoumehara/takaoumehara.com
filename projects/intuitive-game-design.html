Claude Code Skill · Game design · Game feel · Web audioClaude Code スキル · ゲームデザイン · 手ざわり · Web の音

A game nobody has to explain.誰も説明しなくていいゲームを。

intuitive-game-design is a Claude Code skill for games and interactive experiences a first-time player understands without a tutorial — and that feel right under the hand. It carries three bodies of work: designing and diagnosing intuitiveness, building games around a single mechanic, and implementing sound on the web.intuitive-game-design は、初見の人がチュートリアルなしで理解でき、触って気持ちいいゲームと体験をつくるための Claude Code スキルです。中身は3つ — 直感性の設計と診断、ひとつのメカニクスに絞ったゲーム、そして Web での音の実装。

A tutorial is what you write when the design did not communicate.チュートリアルは、デザインが伝わらなかったときに書くものです。

This skill works the other side of that sentence. First, what the shape of a thing tells a player before they read anything — affordances, cognitive load, natural mapping, and the playtest protocols (CARD, ORID) that find out whether it actually landed. Then the handful of milliseconds that decide whether an input feels responsive or broken: variable jump, coyote time, input buffering, and the juice that makes a hit register. Sound is the third part, because on the web a silent game reads as unfinished.このスキルは、その一文の反対側を扱います。まず、読む前に形が伝えること — アフォーダンス、認知負荷、ナチュラルマッピング、そして本当に伝わったかを確かめるプレイテスト手順（CARD・ORID）。次に、入力が「効いている」か「壊れている」かを分ける数十ミリ秒 — 可変ジャンプ、コヨーテタイム、入力バッファ、当たった感じを出す Juice。3つめが音です。Web では、無音のゲームは未完成に見えるので。
