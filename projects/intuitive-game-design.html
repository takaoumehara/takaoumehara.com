01 · Problem

Bloated prototypes with unfocused mechanics

Game projects frequently accumulate disjointed mechanics that sound fun in brainstorms but feel sluggish, redundant, or confusing once implemented.

02 · The Framework

The five-component evaluation heuristic

Breaks every player action into five atomic criteria: Clarity (instant affordance), Motivation (compelling urge), Response (snappy feedback), Satisfaction (tactile reward), and Fit (system harmony).

03 · Autonomous Critique

AI agent acting as the ruthless playtester

Allows developers to bounce game concepts off an AI critic that grades each mechanic against player psychology models before code is written.

04 · Tuning Loop

Concrete balance adjustments

Provides actionable parameter tweaks (timing windows, input buffering, visual juice) rather than vague opinions, accelerating the path to intuitive game feel.

05 · Proven Impact

Applied across browser games and web prototypes

Successfully guided the mechanic design of games like Emoji Blast, Marubatsu, and interactive educational simulations.
