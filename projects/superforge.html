01 · Problem

The ephemeral context trap

AI coding assistants lose their memory the moment a session is cleared, and output quality resets with it. Rebuilding the same instructions every morning forces developers into brittle prompting routines while burning tokens on redundant reasoning.

02 · Architecture

14 specialist skills across four phases

Instead of relying on a single monolithic prompt, superforge decomposes end-to-end product development into fourteen specialised capabilities: Think (brain, biz, brand), Build (ui, dev, handoff), Prove (test, debug, a11y, secure), and Ship (roast, verify, ship).

03 · Model Tiering

Match task complexity to model cost

Not every subtask requires maximum reasoning capacity. Superforge assesses task difficulty and dynamically routes execution between Claude 3.5 Haiku, Sonnet, and Opus, or local fast models, ensuring rapid iteration without runaway token bills.

04 · Persistent Decisions

Files as the single source of truth

Every skill writes its verified conclusions to structured repository files before reporting back. When an agent context is reset, new agents simply read the existing documents and immediately continue with complete fidelity.

05 · Outcome

Repeatable AI-native software creation

Superforge transforms erratic conversational coding into a deterministic, production-grade engineering workflow. Published as an open-source toolkit on GitHub for Claude Code and modern AI agent environments.
