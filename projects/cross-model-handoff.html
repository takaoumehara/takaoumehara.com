One note and a passphrase carry the work.メモ1つとパスフレーズが、作業を運んでいく。

Switching AI coding tools, or clearing context, usually forces people to explain the work again and loses running state that source control can't capture. cross-model-handoff writes a single .handoff/ note plus an AGENTS.md convention file that any tool reading project instructions can pick up — carried forward by a short, memorable passphrase instead of a long prompt.AI のコーディングツールを切り替えたり、コンテキストを消したりすると、ふつうは背景をもう一度説明することになり、しかも Git では残せない「作業途中の状態」まで消えてしまいます。cross-model-handoff は、プロジェクトの指示を読むツールならどれでも拾える .handoff/ のメモと AGENTS.md の規約ファイルを書き出します。引き継ぎに要るのは、長いプロンプトではなく、短くて覚えやすいパスフレーズ一つです。
