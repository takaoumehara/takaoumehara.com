One note and a passphrase carry the work.

Switching AI coding tools, or clearing context, usually forces people to explain the work again and loses running state that source control can't capture. cross-model-handoff writes a single .handoff/ note plus an AGENTS.md convention file that any tool reading project instructions can pick up — carried forward by a short, memorable passphrase instead of a long prompt.
