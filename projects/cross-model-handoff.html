01 · Problem

The multi-model fragmentation dilemma

Developers often prefer Claude for architecture, Codex for bulk code generation, and Gemini for deep analysis. However, moving between them traditionally requires copy-pasting messy chat history.

02 · Capsule Schema

Self-contained repository capsules

Defines an open schema in `.handoff/` that documents active goals, verified invariants, completed steps, modified files, and known pitfalls in concise structured formats.

03 · Delegation

Handing off to asynchronous cloud agents

Enables developers to package up an entire subsystem task and dispatch it seamlessly to cloud workers like Devin or background subagent runners with crisp completion criteria.

04 · Verification

Invariant contracts before execution

When a new model picks up the capsule, it reads the verification script and tests before modifying source files, ensuring zero regressions occur across handoff boundaries.

05 · Ecosystem

Universal agent tooling compatibility

Works out-of-the-box across Claude Code, Cursor, Antigravity IDE, GitHub Copilot Workspace, and standalone shell scripts.
