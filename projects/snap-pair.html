Snap Pair

A lightweight React and Firebase pairing protocol that lets every phone in the room join an app in one scan, with presence heartbeats, capacity limits, and automatic room cleanup.

01 · Problem

The high barrier to multi-device web apps

Getting multiple users or auxiliary mobile screens into a shared session usually requires app store downloads, Bluetooth pairing dialogs, or account registrations that destroy spontaneous engagement.

02 · Protocol

Zero-install rendezvous handles

Snap Pair generates a visual QR code and a 6-character human-readable code. Scanning the QR opens a lightweight web app that directly attaches to the room channel in under a second.

03 · State Engine

Symmetric real-time synchronization

Built on top of Firebase Realtime Database primitives, Snap Pair maintains continuous presence heartbeats, coordinates room membership, and cleans up abandoned sessions automatically.

04 · Agent Integration

A Claude Code skill for rapid builds

The package includes a comprehensive agent skill that automates the integration of multi-device controls into any frontend project with guaranteed security rules and data contracts.

05 · Applications

Living-room commerce, party games & workshops

Powers interactive dual-device experiences such as ten-foot shopping interfaces, shared whiteboards, audience buzzers, and multiplayer web simulations.
