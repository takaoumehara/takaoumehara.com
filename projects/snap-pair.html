Realtime Library · Claude Skill · React + Firebaseリアルタイムライブラリ · Claude スキル · React + Firebase

Every phone in the room joins your app in one scan.その場のスマホが、QR を1回読むだけでアプリの一部になる。

Snap Pair is a React + Firebase realtime pairing layer: QR or six-character code, presence heartbeat, room capacity, and security rules included. It ships with a Claude skill that writes safe integrations for you — so an agent can add multi-device play to any app.Snap Pair は、React と Firebase でつくったリアルタイムのペアリング機構です。QR または6文字コードでの接続、参加者が生きているかの確認、部屋の定員管理、セキュリティルールまで一式入っています。安全な組み込みコードを書いてくれる Claude スキルも付いているので、エージェントがどんなアプリにも複数端末での同時利用を足せます。

Realtime Libraryリアルタイムライブラリ Claude Skill React + Firebase MIT
GitHub ↗ See it live — Fire TV demo →実物を見る — Fire TV のデモ →

Pairing, presence, and security — already solved.つなぐ、生きているか確かめる、守る。そこは全部済んでいます。

Safe, temporary multi-device experiences repeatedly need the same difficult foundation: pairing, presence, shared state, room capacity, and authorization. Snap Pair packages a React hook plus Firebase Auth, callable Cloud Functions, Realtime Database rules, cleanup, tests, and a one-file Lite example — so you build the experience, not the plumbing.その場限りで安全に複数端末をつなぐ体験には、毎回まったく同じ面倒な土台が必要になります。端末をつなぐ、誰がまだ居るかを把握する、状態を共有する、定員を守る、権限を確かめる。Snap Pair は、React のフック、Firebase Auth、呼び出し型の Cloud Functions、Realtime Database のセキュリティルール、後片づけの処理、テスト、そして1ファイルで動く軽量サンプルまでまとめて入れました。配線工事ではなく、体験そのものをつくることに時間を使えます。
