Realtime Library · Claude Skill · React + Firebase

Realtime Library Claude Skill React + Firebase MIT

Every phone in the room joins your app in one scan.

Snap Pair is a React + Firebase realtime pairing layer: QR or six-character code, presence heartbeat, room capacity, and security rules included. It ships with a Claude skill that writes safe integrations for you — so an agent can add multi-device play to any app.

Pairing, presence, and security — already solved.

Safe, temporary multi-device experiences repeatedly need the same difficult foundation: pairing, presence, shared state, room capacity, and authorization. Snap Pair packages a React hook plus Firebase Auth, callable Cloud Functions, Realtime Database rules, cleanup, tests, and a one-file Lite example — so you build the experience, not the plumbing.
