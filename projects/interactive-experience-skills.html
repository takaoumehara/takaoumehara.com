01 · Problem

The lack of tactile taste in AI-generated code

AI coding assistants routinely reach for linear keyframes, generic easing functions, and layout-thrashing DOM animations, producing stiff and unnatural user experiences.

02 · Physical Modeling

Spring mechanics over arbitrary durations

Equips agents with mathematical formulas for harmonic oscillators, velocity preservation on gesture release, and contextual dampening parameters.

03 · Gestalt Principles

Closure and visual containment without boxes

Guides agents to organize user interfaces using whitespace, negative space, and suggested shapes rather than boxing every element inside borders and heavy cards.

04 · Performance Guardrails

Hardware acceleration without compromises

Enforces strict CSS animation best practices: animating only transform and opacity, utilizing view transitions, and verifying zero Jank.

05 · Accessibility

Full motion sensitivity support

Every interaction pattern includes immediate, tested compliance with `prefers-reduced-motion`, providing instant non-animated state transitions for motion-sensitive users.
