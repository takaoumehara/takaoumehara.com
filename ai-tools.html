Pairing, presence, and security — already solved.ペアリングも、プレゼンスも、セキュリティも、解決済み。

A React + Firebase realtime pairing layer: QR or six-character code, presence heartbeat, room capacity, and security rules included. It ships with a Claude skill that writes safe integrations for you — so an agent can add multi-device play to any app.React + Firebase のリアルタイムペアリング層。QR または 6 文字コード、プレゼンスハートビート、定員管理、セキュリティルールまで同梱。安全な統合コードを生成する Claude スキル付きで、エージェントがどのアプリにもマルチデバイス機能を組み込めます。

02 · failforward02 · failforward

Your coding agent stops repeating yesterday's mistakes.エージェントが、昨日と同じ失敗を繰り返さなくなる。

CLI Claude Code Skill + Hook Codex · Gemini · Qwen ready対応 MIT

Every failure recorded. Every lesson recalled.すべての失敗を記録し、すべての教訓を呼び出す。

A zero-dependency CLI plus Claude Code skill that records every build, test, and lint failure as plain Markdown — then recalls the relevant ones before similar work begins. Convention files extend it to Codex, Gemini, and Qwen.依存ゼロの CLI + Claude Code スキル。ビルド・テスト・リントの失敗をプレーンな Markdown で記録し、似た作業が始まる前に関連する失敗を呼び出します。規約ファイル経由で Codex・Gemini・Qwen にも拡張できます。
