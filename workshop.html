Core Methodology

The 8 BreakBias Systematic Transformation Tools BreakBiasの核となる8つの思考変形ツール

Unlike standard brainstorming where volume replaces rigor, BreakBias applies proven cognitive transformations directly to existing product components. 根拠のない自由連想ではなく、既存の要素に対して体系的な操作を加えることで確実な新解を導きます。

01. Subtraction

Remove a seemingly indispensable element and force the system to perform without it.

02. Division

Deconstruct a unified component physically or temporally and relocate its function.

03. Multiplication

Duplicate an existing part while giving the copy a modified, non-identical responsibility.

04. Task Unification

Assign a brand-new role to an existing component or to an ambient resource in the environment.

05. Attribute Dependency

Link two previously independent variables so change in one dynamically alters the other.

06. Inversion

Flip standard user flows, hierarchies, or business model assumptions completely upside down.

07. Extreme Constraint

Drastically cut time, budget, interface size, or dependencies to trigger radical shortcuts.

08. Intent Scaffolding

Decompose high-level human intent into precise agentic logic rules and automated workflows.
