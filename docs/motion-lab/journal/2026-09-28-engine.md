# 2026-09-28 — エンジン v2 の土台（engine-contract.md の実装）

- **motion.json → v2**: `version: 2` と `transition` / `boot` / `idle` / `sound` / `interactions` を追加。v1 の値は 1 つも変えていない。
- **読み込み**: v1→v2 の変換は `src/scripts/motion-config.mjs` の `upgradeConfig()`（DOM なし・Node でテスト可）。motion.js の `resolveConfig()` はこれを呼ぶだけ。スタイルの `params` だけは自由形式で素通しし、再生時に `resolveParams()` が既定・min/max・型をかける。
- **レジストリ**: `src/scripts/styles/index.mjs`。core = cover `none` / reveal `box-first`・`cut` / boot `odometer` / idle `none`。box-first と odometer は motion.js が自分で `run()` するので、registry 側の `play()` は呼ばれない。
- **スタブ**: `styles/{slabs,field,wipe,band,boot-slabs,idle}.mjs`（空配列）、`styles/sound.mjs`、`motion-interactions.mjs`、`motion-export.mjs`、`motion-pick.js`、`data/tints.json`。担当者は自分のファイルの中身だけ差し替える（export 名は変えない）。
- **エンジンの流れ**: before-preparation で `cover.in` ∥ `paneOut` → swap → `holdMs` → `cover.out` と（`revealDelayMs` 後に）reveal → settle 後に `idle.start`。負の `revealDelayMs` は reveal が先で、幕は |d| 後に上がる。`holdMs` は ms そのまま（`k` を掛けない）。
- **不変性**: cover none / box-first / odometer / idle none のときは、分岐 1 回のあと v1 と同じ関数を同じ順で呼ぶだけ。テストで「v1 JSON の読み込み結果 = 同じ JSON に v2 既定ブロックを足したもの」「v1 部分は旧 resolveConfig と deep-equal」を固定。
- **幕の後始末**: 幕は `<html>` 直下の `.mo-overlay`（z-index 900、Lab パネル 1000 より下）。`finishAll()`（入力）・`cancelOut()`（loader 失敗・bfcache 復帰）・新しい遷移で必ず消える。例外は `reset()` が幕の下で走るときだけ（`coverLive`）。swap が来なければ 10 秒で強制撤去。古い遷移の ctx は `layer()` が DOM に付かない要素を返し、`drop()` も自分の世代の要素しか消さない。
- **idle の例外**: idle の `ctx.own()` は入力の `finishAll()` では止めない（クリックのたびに呼吸が止まるため）。止めるのは次の遷移・replay の `stopIdle()`。
- **ブラウザ確認（dev + Playwright）**: /lab/stage の初回・「Page change」とも、コンソールエラー 0、`#main`/`#side` のテキストがサーバー HTML と完全一致、`.mo-layer`・`.mo-overlay` 残りなし。仮の cover を registry に足した replay("nav") と本物のサイト遷移（/work → /projects/resona.html）で、幕が swap をまたいで残り、上がって消えることを確認。入力（finishAll）で幕が即消えることも確認。/?lab=1 に Transition グループ、cover 選択肢 `none`、Export code（読み取り専用）。
- **後の担当者へ**:
  - dev サーバーでファイルを書き換えると、Vite がページ側の import に `?t=` を付ける。コンソールから `import("/src/scripts/motion.js")` すると別インスタンスになるので注意。
  - v1 からある小さな癖（コードを読んだ限り）: 遅い画像の「LOADING」ラベルが busy タイマーのあとで消えると、空の `.mo-layer` が残ることがある（見えない・無害、今回は触っていない）。
  - `ctx.tint` は、遷移前（cover.in）は行き先の slug で `tints.json`、遷移後は `html[data-tint]` → `tints.json` の順。無ければ null。
