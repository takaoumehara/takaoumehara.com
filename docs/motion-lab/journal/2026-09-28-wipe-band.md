# 2026-09-28 — 幕 3 種の復元（H2 ワイプ・B5 帯スイープ・B4 ディゾルブ）

- **`styles/wipe.mjs`**: cover `wipe`（H2）。`ctx.layer("wipe")` に ink の幕を 1 枚。`direction`（ltr/rtl/ttb/btt）の側から `translateX/Y(±100%) → 0`（decel）で入り、全面を覆ったら `in` が resolve。`out` は反対側へ `0 → ∓100%`（accel）で抜けて `ctx.drop`。`text` を入れると paper 色・`--pr-ff-display` で中央に出る（既定 "" = 文字なし）。`edge: slant` は幕を進行方向に 120% にし、先頭辺だけを静的な `clip-path: polygon()` で斜めに切る（止まった位置で必ず全面を覆う）。
- **`styles/band.mjs`**: cover `band-sweep`（B5）。幅 `bandPct`%・`angle`° 傾けた帯（`ctx.tint` か ink→paper のグラデーション）が左から右へ。帯だけでは画面を覆えないので、`in` は帯が中央に着くまで（前半 = durationMs/2、ease-in）＋同時に帯の 1 色目の面を opacity 0→1。`out` は面が消えつつ帯が残り半分を ease-out で抜ける（中央での速度が揃う組み合わせ）。
- cover `dissolve`（B4）: paper の面を opacity 0→1 / 1→0。reveal `dissolve`: `#main` を `fill: "none"` で 0→1。インライン style は一切書かない（終われば元の不透明度）。
- 共通: `ctx.still` で即 resolve、全 Animation を `ctx.own`、`finished` の reject は握りつぶし、`ctx.capMs` を超えたら自分で `finish()`。色は `ctx.tokens` / `ctx.tint` のみ。
- **速度の注意**: 本番設定は `speed 1.7 × navSpeed 3.25` なので `ctx.k ≈ 0.18`。wipe の 700ms は実際には約 130ms で、ほぼ「一瞬の黒」に見える。H2 らしく見せたいなら Lab で `durationMs` を上げるか navSpeed を下げる。
- **テスト**: `tests/styles-wipe-band.test.mjs`（6 件）。登録・既定値・`resolveParams` の丸め（bandPct 999→60、未知の direction→ltr）、ソース規則（gsap / @keyframes / blur( / hex なし）、`{ still: true }` で全関数 resolve。
- **ブラウザ確認**（dev :4303 + Playwright, /lab/stage, `replay("nav")`）: wipe（文字あり / ttb / rtl+slant）・band-sweep・dissolve の全てで、`in` resolve 時に幕が画面中央を覆う（band は帯の中心 x = 640/1280、面 opacity 1）、終了後 `.mo-overlay` 0、`#main` に "Motion Lab"、`#main` のインライン opacity/transform なし、コンソールエラー 0。reveal dissolve（cover none）は 0.01→1.00 と上がり、終了時 computed opacity 1・`style` 属性なし。
