# 2026-09-28 — 舞台を自サイトから離す（/lab/motion をツールの家に）

- **/lab/motion**: リダイレクトをやめ、全画面のツールに（Site.astro の外、noindex）。左 = 操作（舞台／Preset・Cover・Reveal／Replay load・Page change／Phone check／Fine-tune → `/?lab=1`／Keep or toss（`mountPick`）／Copy JSON）、右 = 舞台の iframe。スクリプトは `src/scripts/lab-tool.js`、見た目は `src/styles/lab-tool.css`。舞台（/lab/stage）が本番で build されない間は、本番の /lab/motion は従来どおり `/?lab=1` へ（meta refresh）。
- **舞台は 3 種**（`/lab/stage?stage=…`、同じエンジンを再生。組み立ては `src/scripts/stage.js`）:
  - `site`（既定）: Takao のサイトの縮小版。見た目は変えていない。
  - `shot`: スクショを `rows × cols`（既定 4 × 3、2〜6）の `.bento-cell` タイルに切り、背景位置を合わせて 1 枚に見せる（覆う・上揃え・リサイズで再計算）。上に H1 = `?title=`（既定 "Your site"）。画像が届くまでは点線の「Drop a screenshot in the tool」。レールは出さない。
  - `peek`: URL のメタデータからテンプレ（ティーザー画像・H1・一行・グレーのカード 2 枚・画像の 3 分割）。
  - `?frame=phone` は幅に関係なくスマホ配置（`html.st-phone`、560px のメディアクエリと同じ規則）。`?bar=0` で下のバーを隠す。
- **メッセージ**（postMessage、同一オリジンのみ受け付ける。HTML は書かず textContent / src / style だけ）:
  - ツール → 舞台: `{ type: "stage:config", config }`（setConfig + replay("load")）／`{ type: "stage:replay", kind: "load" | "nav" }`／`{ type: "stage:shot", dataUrl, title }`／`{ type: "stage:peek", title, description, image, site }`
  - 舞台 → ツール: `{ type: "stage:ready" }`。ツールはこれを受けてから、その舞台に現在の config と shot / peek を送り直す（iframe を読み直しても状態が戻る）。
  - 画像は URL に載せない（長すぎる）。最大 4 MB、ファイル選択・ドロップ・クリップボード貼り付け。
- **スマホ確認は既定 ON**: `localStorage["tu-lab-phone"]` が `"0"` のときだけ OFF。ON なら 390 × 760 の iframe（`&frame=phone`）を横か下に出す。
- **config**: `{ ...PRESETS[preset], transition: { cover, reveal } }` を親で `motion.setConfig` し、解決済みの v2 を全舞台へ。プリセット既定と違えば `preset` は `"… (edited)"`。`mlab:config` も舞台へ転送。
- **Keep or toss の api**: `candidates(n)`（ランダムな preset + cover、30% でランダムな box-first 以外の reveal、名前は "Terminal + Slab curtain · 4-way offset" 形式）／`play`／`apply`（select を合わせ、`tu-motion-lab` に保存 + `sessionStorage["tu-lab"]="1"`）／`copy`。
- **/api/lab/peek**（公開・on-demand）: `?url=` は http/https だけ。localhost・127.・10.・192.168.・172.16〜31.・169.254.・0.・::1・fc/fd・fe80・::ffff:・.local・.internal は 400。リダイレクトは手で最大 3 回たどり、**毎回**同じ検査（`redirect: "follow"` だと社内アドレスへ飛ばされうるため）。5 秒で打ち切り、300 KB まで読む、HTML 以外は 415、取得失敗・非 2xx は 502、成功は `Cache-Control: public, max-age=300`。charset はヘッダか `<meta charset>` に従う。
- **限界**: ホスト名が DNS で私設 IP を指す場合（DNS rebinding）は検査していない。解析は正規表現で `<title>` と meta だけ、JS で描くページの中身は読めない。
- **確認**: `node --test tests/lab-tool.test.mjs`（fixture で parsePeek、ホスト検査、ソース検査）。Playwright で /lab/motion: iframe 2 枚・両方 ready、cover（slabs.quad-stagger）が Page change で幕を出し、Replay 後も #main のテキストはサーバー HTML と一致・幕残りなし、Phone OFF で 1 枚（再読み込み後も）、スクショで 12 タイル + H1、URL（API は fixture）で題名、reduced motion で注記・再生なし、コンソールエラー 0。
