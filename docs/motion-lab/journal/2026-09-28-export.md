# 2026-09-28 — Export code（`src/scripts/motion-export.mjs`）

- **何が出るか**: `exportCode(config) → { css, js, note }`。純関数（DOM なし・Node で動く・例外を投げない）。Lab の「Export code」がそのまま IO 欄に出す。
- **CSS**: `--ml-speed` / `--ml-cover-ms` / `--ml-hold-ms` / `--ml-ink` / `--ml-paper`（config に `tint: [c1, c2]` があれば `--ml-tint-1/2`）、`.ml-cover`（fixed・全画面・`pointer-events:none`・z-index 900）、選んだ幕に要る静的スタイルだけ、`prefers-reduced-motion` で `.ml-cover` を消す規則。
- **JS**: import なしの IIFE。`window.MotionLab = { cover(), reveal(), play(swap) }`。幕は `none` / `slabs.quad-stagger` / `slabs.quad-center` / `slabs.split-sharp` / `slabs.split-round` / `slabs.dynamic` / `field` / `wipe` / `band-sweep` / `dissolve`。選んだ 1 種のテンプレートだけを埋め込み、params は定数 `P` に入る（最大でも 116 行）。
- **params の既定**: レジストリ（`styles/*.mjs`）に登録済みなら、その既定と min/max を使う（Lab のプレビューと同じ値）。未登録なら export 側の既定。型・選択肢・範囲を確認し、文字列は `</script>` を壊さないようエスケープ。
- **時間**: すべて `ms / SPEED`（`SPEED = global.speed`）。`holdMs` はエンジンと同じく素の ms。入力（pointerdown / keydown）で走っている Animation を全部 `finish()`、hold も飛ばす。reduced motion では何も描かずに swap だけして即 resolve。終わったら `.ml-cover` を DOM から外す。
- **reveal**: `cut`（何もしない）と `dissolve`（`config.exportTarget ?? "main"` を 0→1）。`box-first` は再現しない（cut として出し、note に書く）。
- **出ないもの**: box-first の outline / fill / text / media の振付、boot、idle、sound、interactions、navSpeed・capMs・revealDelayMs。これらは JSON かサイトの motion.js で。
- **貼り方**: CSS をスタイルシートへ、JS を `</body>` の前へ。遷移のたびに `MotionLab.play(() => swapYourContent())`。
- **エンジンとの差（意図的）**: アニメーションは `fill: "both"`（stagger の delay 中に幕が最終位置に見えないため）。速度は `global.speed` だけ（サイトの遷移は `navSpeed` も掛かるので、サイトより遅く見える）。
- **確認**: `node --test tests/motion-export.test.mjs`（18 件）。Chromium で 10 種すべて: swap の瞬間に画面 9 点が幕で覆われている、終了後 `.ml-cover` 0・h1 差し替え済み・コンソールエラー 0。reduced motion で幕 0 回・1 ms で resolve。80 ms で pointerdown → 5〜18 ms で幕が消える。`/?lab=1` の Export code に `.ml-cover` と `window.MotionLab` が出る。
