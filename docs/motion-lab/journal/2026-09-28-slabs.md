# 2026-09-28 — H3b スラブ幕 5 種（`src/scripts/styles/slabs.mjs`）

- **移植したもの**: living-architectural-slabs-v4.html の 5 つのトランジションを cover スタイルに。`slabs.quad-stagger`（H3b-1 四隅から時間差、逆順で退場）、`slabs.quad-center`（H3b-2 四象限が同時に中央へ）、`slabs.split-sharp`（H3b-3 角なし左右 2 枚 → 上下へ裂ける）、`slabs.split-round`（H3b-4 角丸版）、`slabs.dynamic`（H3b-5 n×n 市松、各スラブがランダムな辺から来てその辺へ流れ去る、退場順はシャッフル）。
- **作り**: 1 スラブ = 1 つの `el.animate()`（transform のみ）、全部 `ctx.own()`。`in()` は到着が全部 settle したら resolve（= 画面が覆われた）、`out()` は退場後に `ctx.drop("slabs")`。どちらも `ctx.capMs` で自分から finish。`ctx.still` なら何もせず即 resolve。色は `ctx.tokens.ink / paper`、墨スラブの縁は `ctx.tokens.line`。
- **params**: 全スタイル `durationMs`（620, 100–2000）・`staggerMs`（60, 0–300）・`snap`（true: 開始で swoosh、到着完了で snap）。`radiusPx`（22, 0–48）は split-sharp 以外。dynamic は `grid`（3, 2–5）。
- **原本との違い**:
  - イージング: 到着は GSAP power3/expo.out → `ctx.ease("decel")`。退場の power4.in は EASINGS に近いものが無いので `cubic-bezier(0.64, 0, 0.78, 0)`（easeInQuint）を直書き。
  - 時間: 原本は到着 0.28–0.3s・退場 0.24–0.25s・stagger 15–50ms。ここでは既定 620ms（退場はその 0.85 倍）× `ctx.k`、stagger 60ms × `ctx.k`。nav 再生では k≈0.18 なので実時間は原本より少し速い。
  - 0.3s の「ため」は原本の timeline 内ではなくエンジンの `transition.holdMs` が持つ。
  - stagger の意味: quad-stagger と dynamic は到着と退場、quad-center と split は「同時に閉じる」原本に合わせて退場の間隔だけ（split は 2 枚目の遅れ、原本 20ms）。
  - dynamic の下敷き（全面の黒 underlap）は入れていない。原本では開始の瞬間に画面が黒く切り替わるため。スラブ同士が 4% 重なるので到着後は隙間なく覆う（下の確認）。
  - スラブ内の文字（ラベル・コピー）、影、ホバーは省略。fill は到着・退場とも `"both"`（delay 中に画面上へ一瞬出ないように）。
- **確認**: `node --test tests/styles-slabs.test.mjs` 5/5 pass。Playwright（dev :4301, /lab/stage, 1280×800）で 5 種それぞれ `replay("nav")`: 150ms 時点で `.mo-overlay` に 4/4/2/2/9 枚、9×9 点の被覆は 4 種が 150ms で 81/81、dynamic は 150ms で 72/81（まだ到着中）→ 172ms で 81/81。終了後 `.mo-overlay` 0、`#main` の h1「Motion Lab」そのまま、コンソールエラー 0。100ms 時点の pointerdown（finishAll）で幕は 1ms で消えた。
