# 2026-09-28 · H1 グラデーション・フィールドの復元

- **復元したもの**（`references/handoff.js` → `src/scripts/styles/field.mjs`）: `--tu-field` の定義をそのまま移植した。radial ×2（`122% 92% at 18% 10%` に c1 を oklab で白へ 74%、`104% 84% at 84% 90%` に c2 を黒へ 84%）+ linear（既定 152°）。
  - `field`（cover）: handoff.js の veil を幕にしたもの。opacity 0→1 を 420ms（`veilMs`）で上げ、swap のあと 440ms（`liftMs`、decel）で下げる。`lift: "up"` にすると translate で上へ抜ける。「色 → ページ、白は挟まない」の形。
  - `field-lift`（reveal）: 同じ veil を reveal だけで使う形。行き先の色を 0.9 から 0 に抜く（440ms）。
  - 色は `ctx.tint`（`src/data/tints.json` か `html[data-tint]`）。無ければ `ctx.tokens` の ink / paper で描く。
- **tints.json**: 旧 landing の 12 組（`references/tints.txt`）を、今のサイトの slug に付け直した。hex は原文のまま。外部 URL の 3 つは `kao-game` / `resona` / `typespace`。
- **落としたもの**:
  - image（押したサムネイルが全面まで飛ぶ形）: 幕はクリックした要素を受け取らないので、`.tu-ghost` を組む材料が無い。やるなら別スタイルで、ctx に要素を渡す契約の変更が要る。
  - ホバーで地が点く演出: 遷移ではなくホバーの手触りなので、今回は範囲外。
  - 保持 280 / 440ms: エンジンの `transition.holdMs` が持つので、スタイル側には置かない。`sessionStorage` の受け渡しと `<head>` での同期ロードも、`<html>` 直下の幕が swap をまたいで残るので要らない。
- **確認**: `node --test tests/styles-field.test.mjs` 7/7。Playwright（dev サーバー）で
  - `/lab/stage` cover=field: 200ms 時点で `.mo-overlay` が gradient、opacity 1。終了後は overlay 0 個、「Motion Lab」の文字はそのまま。
  - cover=none + reveal=field-lift: 最大 opacity 0.9 で gradient を描き、終了後は消える。
  - `/projects/verizon-ai-agents.html` から rail で `/projects/resona.html` へ: 幕が `linear-gradient(152deg, rgb(6, 35, 31) 0%, rgb(13, 93, 85) 100%)`（resona の色）。tint の無い `koe-baku` へは ink / paper（`rgb(0, 0, 0)` → `rgb(255, 255, 255)`）に落ちた。console error 0。
