## 0. 対象と、Takao が決めていること

**対象（Domain A: 道具そのもの）**: 仮想サイトの上でローディング・ページ遷移・
マイクロインタラクションを試し、独自の表現を作って、その設定を JSON として他の開発
（人・AI セッション）に持ち出せる道具。いまの `/lab/stage` と `motion.json` が原型。

**Takao の決定（掃引で覆さない。制約として全セルの前提にする）**
1. **簡単に使えること**が最優先。複雑さで独自性を買わない。
2. 使うのは **一般の人（デザイナーに限らない）**。**ウェブサービスとして公開し、課金を目指す水準**。
3. **AI に相談できる**。AI に**新しい表現を作ってもらう**ことも、**既存のものを混ぜて**もらうこともできる。
4. **音**もインタラクションの一部として入ってよい。
5. **参照元**: いつも格好いいサイトを（裏で）巡回して技を取り込む。**話題のライブラリ**も使えるようにする。
6. **モバイル**でちゃんと動くかの検証を、希望制で選べる。**既定は ON**。

**JTBD（利用者の言葉で）**: 「自分のサイトやアプリのローディングや遷移を、ありきたりでない
ものにしたい。でも動きの実装は難しく、Framer のプリセットを使うと他と同じ顔になる。
いまは Awwwards を眺めて諦めるか、開発者に口で説明して妥協している。」

## 1. Closed World（箱の中）

箱の中にあるもの以外を持ち込まない。箱の中は次のとおり:
- 道具の部品（§3 の要素）、仮想サイト、設定 JSON、Motion Lab のパネル、Jev の判定
- 利用者（一般の人・デザイナー・開発者・AI セッション）、利用者のサイト、訪問者、訪問者の端末と回線
- AI（相談・生成・混合・判定）、参照元の巡回（格好いいサイト）、外部ライブラリ（GSAP / Motion / Rive / Lottie / Three 等）
- 音、時間（初回・再訪・時間帯）、実際の読み込み進捗、アカウントと課金
- Takao の過去の演出（`docs/motion-archive.md` A〜H）

## 2. 先に禁止する平凡 3 案（**生成では出さない**。掃引後に一度だけ再訪する）

1. プリセット一覧＋スライダーの GUI（Framer / Rive 型）
2. 「こんな感じにして」と書くと JSON を返すチャット欄
3. 演出の見本集（Awwwards / Codrops 型ショーケース）

セルの結論がこの 3 つの言い換えになったら、そのセルはやり直す（別のサブ手法・別の
「ありえない形」から）。ただし**禁止はこの 3 つの「形」だけ**。プリセットやスライダーや
チャットという部品が案の一部に登場すること自体は禁止しない。

## 5. セルの書き方（1 セル = 1 行の JSON。`docs/motion-lab/breakbias/ledger/cells-<A|B|C|D>.jsonl`）

```json
{"cell_id":"A-S1-1","element_id":"S1","element":"仮想サイト（ステージ）","technique":"Subtraction","sub_method":"除去のみ",
 "bias":"実サイトの縮小コピーであるべき",
 "impossible_form":"（技法を当てた"ありえない"状態。判断は保留して形だけ書く）",
 "benefit_provider":"（形から逆算した、提供側の利点）",
 "benefit_user":"（利用者側の利点）",
 "market_feasibility":"（市場はあるか・実現に何が要るか。1〜2 文）",
 "alt_without":"（代替しない版は成立するか）",
 "alt_with":"（取り除いた機能を箱の中の別要素で代替した版）",
 "concept":"（コンセプト名。日本語。必要なら EN を括弧で）",
 "broken_bias":"（壊した思い込みを 1 文で）",
 "prior_art":{"exists":false,"where":""},
 "status":"generated"}
```

**ルール（守らないセルはやり直し）**
1. **形が先**: `impossible_form` を先に握り、利点はそこから逆算する。「良さそうな案」から書き始めない。
2. **Closed World**: §1 の箱の外から要素を足さない。
3. **禁止 3 案の言い換えは書き直す**（§2）。
4. **生成中に間引かない**: 弱い・既にある・難しい、は書く理由であって捨てる理由ではない。全セルを埋める。
5. **既出は殺さず印だけ**: 似たものがあれば `prior_art.exists=true` にして `where` に名前（Framer, Rive, GSAP ShowcaseX, Codrops, Vercel の◯◯ 等）を書く。それで終わり。勝ち筋の判定は後工程。
6. **番号を飛ばさない**: `A-S1-1`, `A-S1-2`, `A-S2-1` … の順に全要素・全サブ手法を通す。省略記号で済ませない。
7. **Takao の 6 つの決定（§0）を破らない**。「簡単に使える」を犠牲にする案は `market_feasibility` にそれを正直に書く。
8. 言語は日本語。1 セル 120〜220 字程度の密度。
