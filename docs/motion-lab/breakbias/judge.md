# 審判 — 生き残ったセルの採点（別コンテキスト・生成過程は見せない）

> 2026-09-28 · 入力: カード（1 文・なぜ意外か・利用者の価値・事業の価値・リスク・次の実験）だけ · 出力: `ledger/judgments-<group>.jsonl`
> 審判は **要素・技法・サブ手法・ありえない形・逆算の過程を見ない**。見えるのはカード、禁止 3 案、下の基準だけ。

## 1. 4 軸、各 1〜10。合計しない

| 軸 | 問い |
|---|---|
| **N** Novelty | 禁止 3 案からどれだけ離れているか |
| **W** Wow | 見た人が「それは見たことがない」と言うか |
| **U** User Impact | 利用者の具体的な痛みが消えるか |
| **C** Company Impact | 収益経路が見えるか（Takao の決定 2: 一般向け web サービス・課金を目指す） |

### N の基準
| 点 | 意味 |
|---|---|
| 1–3 | 禁止 3 案の言い換え、または業界の標準解 |
| 4–6 | 既存の型の組み替え。説明すれば「なるほど」で終わる |
| 7–8 | 前提が 1 つ壊れている。競合が真似るには方針転換が要る |
| 9–10 | カテゴリの定義が変わる。既存プレイヤーの強みが負債になる |

### U の基準
| 点 | 意味 |
|---|---|
| 1–3 | 「あれば便利かも」。今の代替手段で誰も困っていない |
| 4–6 | 具体的な不満を 1 つ解消する。ただし我慢できる程度 |
| 7–8 | 定期的に発生する痛みが消える。既に金か時間を払って回避している |
| 9–10 | それが無いと成立しない |

### C の基準
| 点 | 意味 |
|---|---|
| 1–3 | 収益経路が想像できない |
| 4–6 | 課金はできるが、単価か頻度のどちらかが弱い |
| 7–8 | 明確な支払い意思がある。既存の類似支出を置き換えられる |
| 9–10 | 需要が構造的に途切れない |

W は「初見の驚き」。N が高くても W が低いことはある（理屈は新しいが見た目は地味）。

## 2. 2 軸と象限（審判は合計せず、2 つの和と象限名を出す）

- **独創軸** = N + W（2〜20） · **事業軸** = U + C（2〜20） · 中点 11。**≥12 が高、≤11 が低**

| | 事業軸 ≤11 | 事業軸 ≥12 |
|---|---|---|
| **独創軸 ≥12** | **Lab** — 面白いが今は金にならない。棚に置く。**戻ってくる条件**を 1 文で | **Hero** — 見たこともなく、需要がある |
| **独創軸 ≤11** | **Discard** — 唯一の正当な廃棄 | **Workhorse** — ありふれているが確実に必要。独創性を上げようとしない |

Workhorse の N が 3 でも欠陥ではない。Workhorse の勝負は勝ち筋（差分・地理・時機・実行）であって驚きではない。

## 3. 追加で出すもの

- **effort**（1〜5）: 作る手間。1 = 1 画面で価値が出る、5 = 全部作らないと成立しない。「次の実験」と「リスク」から推定し、根拠を 1 文。
- **note**: 採点理由を 2 文以内。Lab なら「〜が〜になったら再評価する」の形の**再参入条件**を必ず含める。書けない Lab は Discard として採点し直す。

## 4. 出力の形（1 セル 1 行）

```json
{"cell_id":"A-S1-1","N":6,"W":5,"U":6,"C":4,"effort":2,"note":"…","reentry":null}
```

`reentry` は Lab（独創 ≥12 かつ事業 ≤11）のときだけ文を入れる。それ以外は null。

## 5. やらないこと
- 生成過程を推測して加点しない。カードに書いてあることだけを採点する。
- 「弱いから低く」ではなく、基準表の行に当てる。
- Workhorse の N を上げない。Hero に見せるための再採点をしない。
