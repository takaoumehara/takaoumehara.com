# ポートフォリオ内容ヒアリング指示書（各プロジェクトのAIセッションに貼る用）

## これは何か

各プロジェクト（Rakugaki Jam、Koe Baku 等)を実際に作っているAIセッションは、そのプロジェクトの中身を一番よく知っている。takaoumehara.com のケーススタディを書くたびに一から聞き出すのではなく、**このプロンプトをそのプロジェクトのAIセッションに貼り付けて、内容を書き出させる**ためのテンプレート。

出力はそのまま takaoumehara.com の既存ページ構成（`projects/cli-studios.html` がお手本）に流し込める形式に合わせてある。実際のHTML組み込みは takaoumehara.com 側のセッションで行うので、ここで求めるのは**文章とメディア素材リストのみ**。

---

## 貼り付け用プロンプト（ここから下をコピーして相手のAIセッションに渡す）

```
あなたはこのプロジェクトの開発に携わってきたAIとして、プロジェクトの中身を一番理解している立場です。
このプロジェクトを個人ポートフォリオサイト（takaoumehara.com）のケーススタディとして紹介するための
文章素材とメディア素材リストを、以下のフォーマットに沿って書き出してください。

【重要な原則】
- 知らない数字・日付・役割を推測で埋めない。わからない項目は "不明・要確認" と明記する。
- 誇張しない。実際にあった課題・決定・結果だけを書く。
- 英語(EN)と日本語(JP)の両方で書く(サイトはバイリンガル表示のため)。
- 一人称視点(「私は〜を決めた」「私が設計した」)で書く。

---

## 1. 基本情報
- プロジェクト名(EN / JP):
- 一言で言うと何のプロジェクトか(1文):
- クライアント/対象(自主開発なら "Personal Project"):
- 自分の役割(例: Lead Designer, Full-stack Developer, Prompt Engineer):
- 制作年・期間:
- リンク(公開URL, リポジトリ, デモ動画など。無ければ空欄):

## 2. 一覧カード用の要約(work.html的な使い方)
- カード用タイトル(短縮版):
- カテゴリタグ(2〜3個。例: "App Design", "AI Product", "Design System"):
- 1文の説明(成果が伝わる書き方。例: "◯◯を△△することで□□を実現した"):

## 3. The Tension(課題・背景)— EN/JP
- 誰のどんな困りごと・機会に対して作ったか
- なぜそれが放置できない/面白い問題だったか
- 着手した時点で分かっていたこと・分かっていなかったこと
(2〜4文程度。物語として読めるように)

## 4. My Approach(自分のアプローチ・意思決定)— EN/JP
- 最終的にどんな方針を取ったか
- 検討したが採用しなかった選択肢と、採らなかった理由
- 一番難しかった判断は何で、どう判断したか
(一人称。「なぜその決定をしたか」に重点を置く。実装の逐次説明ではない)

## 5. Tools & Methods
- 使った技術・ツール・手法をタグ的に列挙(例: Next.js, Figma, Claude API, ユーザーインタビュー)

## 6. Outcomes(結果)
- 数値化できる成果があれば2〜3個(大きい数字 + 短い説明のペア)。無理に数字を作らない。
- 数値化できない場合は、定性的な成果(学び、フィードバック、次への発展など)を代わりに書く

## 7. Problems Solved(任意)
- 「課題→解決」のペアがいくつかあるプロジェクトなら、Before/After形式で2〜4個列挙
  例: Before: "手動で30分かかっていた" / After: "生成AIで3分に短縮"

## 8. メディア素材リスト(ここが一番重要)
サイトのギャラリーは以下の型を使う。各項目について、
「① 既にある素材で使えるものがあるか」「② AIが今から生成できるか」「③ 本人が新たに撮影/収録する必要があるか」
を明記すること。

- Hero image(トップの大きい画像。横長、プロジェクトの世界観が一目でわかるもの):
- UI screenshot(16:9、実際の画面。フェイクは不可、本物のスクショが必要):
- Dark UI shot(黒背景のUI。あれば):
- Photo(4:3、人が使っている様子・実機写真など):
- Diagram(白背景、構造図・フロー図。AIが生成/清書しやすい):
- Before/After動画(9:16、スマホで撮った操作動画2本。実際の操作の録画が必要):
- Brand asset(ロゴ・アイコンなど):

各項目ごとに以下を明記:
- 素材の有無: [既存あり / 無い]
- 取得方法: [AIが生成する / 本人が撮影・収録する / 未定なので相談]
- 未定の場合、誰が(あなた自身が)いつまでに用意すべきか一言添える

---

以上を、コピペしやすいように見出し付きのMarkdownで出力してください。
```

---

## 受け取った後の使い方(自分用メモ)

1. 各プロジェクトのAIセッションにこのプロンプトを貼って出力をもらう。
2. 出力された「8. メディア素材リスト」を見て、「本人が撮影」項目だけ先に自分でスクショ/画面収録する。
3. 集まった文章と素材を takaoumehara.com 側のセッションに渡し、`projects/cli-studios.html` の構成(Hero → Tags → Tension → Approach → Tools → Outcomes → Gallery)に流し込んでもらう。
4. 現状 20ページ中19ページが旧フォーマット(SITE-PLAN.md参照)なので、新規に書き出した内容はこの新フォーマットで統一していく。
