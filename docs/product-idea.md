# Product idea — Motion Lab（仮想サイトの上で表現を研究し、持ち出せる道具）

> Written by: superforge-brain（BreakBias sweep） · Last updated: 2026-09-28
> Status: draft — 実在の利用者にはまだ確認していない（§Talk to users）
> Upstream: `docs/motion-lab/breakbias/brief.md`（Takao の 6 つの決定を含む）· 台帳: `docs/motion-lab/breakbias/ledger/` · 全案が見える版: `docs/product-idea.html`

## In one sentence
自分のサイトの読み込みと遷移を、**選ぶだけで作り、速さを保証した「生きている仕様」として渡せる**道具。

## The struggle it addresses
「自分のサイトやアプリのローディングや遷移を、ありきたりでないものにしたい。でも動きの実装は難しく、Framer のプリセットを使うと他と同じ顔になる。いまは Awwwards を眺めて諦めるか、開発者に口で説明して妥協している。」

## Why now
- AI コーディングエージェント（Claude Code / Cursor 等）が**文字の仕様から実装できる**ようになり、「JSON を渡す」が実装に直結する（2025〜26）。
- 判定専用の安価なモデル（Jev）と Long Animation Frames API で、**演出 1 本の尺と滑らかさを機械が判定・保証**できる。以前は人手だった。
- クロスドキュメントの View Transitions と Speculation Rules が主要ブラウザに入り、MPA でも遷移演出と事前描画が使える。

## What it is deliberately not
- 1 要素のタイムライン編集ツール（After Effects / Rive の代わりではない）。単位は**ページの旅路**（読み込み → ホバー → クリック → 遷移 → 次ページ）。
- 演出の見本を「見せる」だけの場所。見本は持ち出せる JSON でなければ置かない。
- スライダーが主役の道具。スライダーは選んだ後の引き出し。

## The banned obvious three
1. プリセット一覧＋スライダーの GUI（Framer / Rive 型）
2. 「こんな感じにして」と書くと JSON を返すチャット欄
3. 演出の見本集（Awwwards / Codrops 型ショーケース）

## Hero concepts
（各カードの MVP・検証・リスク・市場は `ledger/meta.json` と HTML の棚に全文）

### Hero 1 — 生きている仕様（Living Spec） · B-S4-2, C-S4-2, B-P4-2, D-P4-1, C-S3-1
- 一行: 書き出した JSON はファイルではなく生きた参照。サイトが購読し、本番の再生（完走・スキップ・端末別のコマ落ち）を持ち帰り、AI 同士が MCP で読み書きし、料金は再生に従う。
- 壊した思い込み: 出力は 1 つの静的ファイル。
- 体験: 決める → script タグ 1 行 → 翌週「スマホの 3 割が途中で飛ばしている」と帰ってくる → AI の修正案を承認すると本番が変わる。貼り直しは無い。
- 事業: サイト単位の月額 ＋ 再生数の従量。LottieFiles Pro / Rive Pro と同じ財布。
- MVP: `<script src=…/m.js?site=ID>` ＋ 予備 JSON ＋ 完走とスキップだけの beacon。まず takaoumehara.com 自身に。
- 検証: 10 サイトが貼る／3 サイトが 2 週目も貼ったまま／実測を見て設定を変えた人 ≥1。
- リスク: 第三者スクリプトを貼る心理的な壁、CDN 障害、従量の説明。
- 次の一歩: 1 週間で live link と beacon を自サイトに。

### Hero 2 — 動きの契約（Motion Contract） · B-F7-1, B-C1-1, C-S21-2, B-S19-2
- 一行: Jev の判定を合否の基準にし、実時間と体感の二重予算・実機のコマ落ち・尺の許容幅を**契約**として渡す。「中位のスマホで 1.2 秒を超えない」を保証して売る。ランタイム 0 個の焼き込みが保証を支える。
- 壊した思い込み: 判定は人の目の代替／速さが唯一の善。
- 体験: 開発者は合格基準だけを受け取り、CI が毎回検査する。落ちたら Lab に戻る。
- 事業: 保証つきの上位段（SLA 型）。チームは Percy / Chromatic に月 150 ドル超を払っている。
- MVP: 既存の `/api/admin/jev/motion` を合否に拡張（閾値を config に）。焼き込みは第 2 段階。
- 検証: 自サイトで 3 回連続 pass／外部 1 チームが CI に入れる。
- リスク: 保証の法的な重さ、判定の誤り、端末の多様性。
- 次の一歩: 1 日で Ask Jev に「合格 / 不合格」の 1 行と閾値の欄。

### Hero 3 — 被り見張り（Sameness Watch） · B-S18-2, C-S18-2, B-S18-1
- 一行: 巡回（決定 5）を「真似る」でなく「被らない」ために使う。公開後も被りを見張り、独自性の点数と空白地図を返す。
- 壊した思い込み: 参考は人が集めて人が真似る／独自性は職人の手仕事から。
- 事業: 独自性の保証を上位段に（ブランド管理の予算）。
- MVP: 道具内の「独自性の点数」1 つ（巡回 200 サイト × 遷移の特徴）。製品として独立させるのは後。
- リスク: 巡回の法務、偽陽性、「被り」の定義。
- 次の一歩: 30 日で巡回パイプラインの試作（特徴だけ保存）。

### Hero 4 — 選ぶだけで作る（Keep-or-Toss Authoring） · A-S3-1, C-C3-2, A-C4-2, D-S3-1, D-S20-1, C-C4-2, B-S22-2
- 一行: 一般の人の作り方を「数値をいじる」から「選ぶ」に。採るか捨てるか、二択の旅、言葉のタイル、再生中の対象をつまむ、親指だけの画面。
- 壊した思い込み: 調整＝数値／デザイナー向けは GUI／演出はデスクトップで作る。
- 事業: 無料の入口（決定 2 の「一般の人」を連れてくる）。課金は Hero 1・2 で。
- MVP: 既存のパネルに「採る / 捨てる」を足し、プリセットを候補として順に出す。1 日。
- 検証: 5 人が説明なしで 3 分以内に「これで行く」。
- 次の一歩: 1 日で /lab/stage に採る／捨てる → 5 人に触ってもらう。

### Hero 5 — 預ける相談（Overnight Consult） · B-S15-2, C-S15-2
- 一行: 相談は即答しない。仮想サイトで検証して通った案か、巡回した実物の再生だけを返す。チャット欄は入口として残るが、返るのは「動いて、通ったもの」。
- 壊した思い込み: 相談と生成は同じ窓口／AI は生成役。
- 事業: 相談 1 回の従量（決定 3 の中核）。
- MVP: 生成 → Jev 判定 → 合格のみ表示、を非同期の 1 本に。
- 次の一歩: 1 週間。

**Reach が全部 2** — 届け方が無い。これが最大の欠点で、§The riskiest assumption に直結する。

## Chosen direction and why
**Hero 4 → Hero 2 → Hero 1 の順に積む。** 入口は「選ぶだけで作る」（無料、決定 1・2）、価値は「動きの契約」（Jev、Unfair 5）、収益は「生きている仕様」（購読と従量）。Hero 3（被り見張り）は道具内の点数として v2、Hero 5 は Hero 2 の非同期版として後から。

一文にすると: **「選ぶだけで、速さを保証した、生きている読み込みを、自分のサイトに貼れる」**。
目に見えて一番になるもの: **保証**（誰も演出 1 本の速さを保証していない）。
わざと下手にやること: タイムライン編集。1 要素の精密な作り込みは After Effects / Rive に譲る。
友人に薦める一文: 「スライダー触らずに好き嫌い押してただけで、うちのサイトの読み込みが決まって、スマホで遅くならない保証つきで開発の人に渡せた」。

## The riskiest assumption
**一般の人がそもそも来るか**（Reach 2）。そして**サイト運営者が動きのために第三者スクリプトを貼るか**。どちらも掃引の中では検証できない。次点: 巡回の法務（Hero 3）。

## Talk to users（未実施）
掃引は全部この頭の中で行われた。300 セルは 80 セルより「同じ前提について丁寧」なだけで、真実に近いわけではない。Hero と Workhorse は正反対の聞き方が要る:
- Hero（Living Spec / Contract）: 「最後に自分のサイトの読み込みを変えたのはいつ？ そのとき何をした？ 何を我慢した？」— 「〜だったら使う？」は聞かない。
- Workhorse（橋のない実装）: 「いまサイトに貼っている第三者のスクリプトは何？ 最後に外したのは何で、なぜ？」
