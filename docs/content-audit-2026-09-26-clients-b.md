with beats-only HTML, and a real `challenge`/`solution` pair (EN+JP) added to
`src/data/projects/<slug>.json`, since none of the 16 evidence records had
top-level `challenge`/`solution` fields before today (only `narrative` /
`angles` prose). Every Challenge/Solution sentence below is drawn from the
legacy page's own existing "Challenge | Solution" bento, "The Opportunity /
My Direction" prose, or `narrative.problem`/`built` — nothing new was
invented; numbers are only ones already in `metrics[]`.

evidence-item fallback in `[slug].astro` (dark theme, name-only fallback
