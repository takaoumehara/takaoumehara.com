## 3. 検討した 3 案と、採った案

| | 案 | 押す軸 | 捨てるもの |
|---|---|---|---|
| **A ★採用** | **Intent Console** — ヒーロー自体が動く作品。意図チップを押すと agent ルーティング演出を経て、実在の実績カードに解決する | **インタラクションが論証そのもの** | 静かな品格・実装の単純さ |
| B | Wall of Proof — 実績 UI を敷き詰めた動く証拠壁 | 証拠の量 | 焦点（「色々ある」は言えるが「一つの主張」が弱る）・画像の重さ |
| C | The Signal — 一行と数字だけ、背景に流体ひとつ | 引き算による自信 | レンジ。かつ「AI が作った上品なポートフォリオ」の平均に最も近い |

**A を採った理由**（好みではなく、このプロダクト固有の理由）:
彼の主張は「AI 時代の体験を設計できる」。それを**説明せずに実演**できるのは A だけで、
しかも実演される中身は彼自身のフレームワーク（intentfirst の「画面ではなく意図から始める」）
そのもの。ヒーローが最初の作品サンプルを兼ねる。

C は「何も決めなかったときにモデルが返す平均」に最も近く、今回の目的（発注したくなる）
とは相性が悪いと判断した。B の証拠量は、A の直下の Proof strip と Playable band で回収した。

## 5. 新しいコンポーネント

### Intent Console（`.console`）
- 左: 疑似入力バー + 意図チップ 5 つ。右: ルーティング表示 + 解決した実績カード。
- チップ押下 → チップ文言をバーにタイプ（22ms/字）→ `Intent → Context → Match → Evidence`
  を 130ms 間隔で点灯 → 回答カードをクロスフェード。全体 ≈ 780ms。
- **入力バーは編集不可**。自由入力にすると「LLM が答える」期待を作ってしまい、
  外したときの損失のほうが大きい。チップは実在プロジェクト 5 件への確定ルート。
- **JS なしでも Verizon の回答が HTML に描かれている**（fold が空にならない）。
- `prefers-reduced-motion` ではタイプもルーティング演出も飛ばして即差し替え。
- 言語切替は `MutationObserver` で `html.lang-jp` を監視して再描画。

### Playable tiles（`.play-tile` × 6）
各タイルが実物の挙動を **canvas で実際に動かしている**。画像アセットはゼロ。

| タイル | 動き | リンク先 |
|---|---|---|
| Typespace | 点群が星座に集まり、また散る。カーソルで押しのけられる | 本体（外部） |
| Rakugaki Jam | **タイル内をドラッグすると描ける**。無操作時は自動描画。完成した線は右の「壁」に転送 | 本体（外部） |
| Resona | バネ物理 + squash/stretch + 残像。カーソル追従 | 本体（外部） |
| Marubatsu | 3 局を自動対戦し、勝ち筋に線を引く | 本体（外部） |
| Koe Baku | 擬音バーストと、端末内レベルメーター。クリックで発火 | 解説ページ |
| EmojiDrop | 落ちてくる絵文字を上下 2 プレイヤーが撃ち落とす | 解説ページ |

共通ハーネス:
- DPR 上限 2、**約 32fps に間引き**、`IntersectionObserver` で画面外は停止、
  `visibilitychange` でタブ非表示時も停止、`prefers-reduced-motion` では 1 フレームのみ描画。
- タイルは `<a>` なので、**8px 以上ドラッグしたクリックは `preventDefault`**（描いたのに
  ページ遷移する事故を防ぐ）。
- canvas は全て `aria-hidden="true"`。意味はすべて隣接テキストが持つ。

## 7. 検証済みの事実（実測、Chromium / Playwright）

- JS エラー: **0**（残るコンソール警告はサンドボックスの CDN 遮断で、ページの問題ではない）

  横スクロールが出ていた。本ページ上の実測欠陥なので index.html は直したが、
  **同じ定義が他 9 ページ（404 / about / ai-tools / breakbias / contact / index-grad /
  index-v1 / index-v53 / intentfirst）に残っている**。本 PR の範囲外として未着手。
- 言語トグルの EN/JP 同時表示リーク: **0 件**（EN / JP 両モードで検査）

## 8. パフォーマンス上の約束

- ヒーローに画像・動画を**置かない**。LCP はテキストで、追加のネットワーク待ちを作らない。
- Playable band の追加転送量は **0 バイト**（すべてコードで描画）。
- 実行コストは間引き・画面外停止・タブ非表示停止で抑えた。
  超えた場合の対処: タイルを 6 → 4 に減らす（`.play-grid` から削るだけで壊れない）。

## 9. 意図的にやらなかったこと

- **フォント・色・余白のトークンは一切変更していない。** 他 30 ページと分裂させないため。
- WebGL / 3D は使っていない。同じ効果が 2D canvas で出るので、上のティアを払う理由がない。
- 音は付けていない（`superforge-ui` §4e の「訪問者が起こしていない音を鳴らさない」に沿う）。
  付けるなら Koe Baku タイルのクリック時が唯一の候補。
- ライブプロトタイプの iframe 埋め込みはしていない。外部 Vercel アプリの framing 可否と
  初期表示コストが読めないため、リンクに留めた。
