# Portfolio category guide

Updated: 2026-08-03

Use the category that best explains **the design problem and the visitor's reason to inspect the work**. Technology tags are secondary; a project does not become AI Product Design merely because AI helped build it or appears in one feature.

## Primary categories

### Agentic UX / AI Product Design

Put a project here when AI behavior is part of the product's core experience and the designer had to make consequential decisions about at least one of these:

- what the AI decides or generates;
- how a person gives intent, context, constraints, or approval;
- how control moves between the person and the AI;
- how uncertainty, errors, evaluation, safety, or trust are communicated;
- how the experience would materially stop working or change identity if AI were removed.

Do **not** put a project here when AI was only used during production, generates incidental copy, extracts data to save typing, or supplies an optional opponent while the main design problem is multiplayer, motion, navigation, commerce, or conventional product UX.

### Interactive

Put a project here when participation is the work: movement, sound, touch, play, real-time input, multiple devices, shared screens, or spatial/installation behavior. The primary evidence should be a working demo or recording of the interaction rather than a static screen.

MediaPipe, WebGL, WebRTC, Canvas, sensors, and computer vision are implementation tags—not admission requirements. An interactive project may also use AI, but it belongs here when the interaction itself is the main design achievement.

### AI Tools

Put a project here when the primary user is a maker, designer, developer, or agent and the output improves how other work gets done. Reusable skills, MCP tools, audits, handoff workflows, and development utilities belong here.

### Product Design

Put a project here when the main problem is a product flow, information architecture, service journey, interface, or design system and neither AI behavior nor embodied/real-time interaction is the central design contribution.

### Brand & Visual

Put a project here when identity, campaign, art direction, graphic systems, film, or visual communication is the main outcome.

## Tie-breaker

Ask these questions in order:

1. If AI were removed, would the product's central user promise collapse? **Yes → Agentic UX / AI Product Design.**
2. Is participation through movement, sound, touch, play, devices, or a shared environment the main thing being designed? **Yes → Interactive.**
3. Is the product primarily used to help someone or an agent make other work? **Yes → AI Tools.**
4. Is the central contribution a product flow or service experience? **Yes → Product Design.**
5. Is the central contribution identity or visual communication? **Yes → Brand & Visual.**

Use one primary category in navigation and add secondary tags on the card. Cross-link a project from another page only when the secondary dimension is important enough to help discovery; do not duplicate it merely because several technologies are present.
